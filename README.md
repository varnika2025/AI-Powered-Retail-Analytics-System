Retail Business Intelligence: From Data Cleaning to AI Forecasting 📊🚀
🌟 Project Overview
This project is a comprehensive End-to-End Data Analysis solution. It demonstrates the full lifecycle of data: from raw messy spreadsheets to automated Python insights and finally to an interactive, AI-powered Power BI dashboard.

🛠️ The Tech Stack (Hybrid Approach)
Excel: Data sourcing and initial structural auditing.

Python (Pandas & Seaborn): Automated data cleaning, correlation analysis, and predictive profit modeling.

Power BI: Advanced visualization, DAX calculations, and AI Time-Series Forecasting.

🚀 Key Accomplishments
Data Integration: Processed and cleaned over 9,000 retail transactions.

Predictive Analytics: Built a Python model to forecast how discount changes affect net margins.

Business Insights: Identified "Technology" as the primary profit driver while uncovering significant losses in the "Tables" sub-category.

Future Forecasting: Implemented a 1-year Sales Forecast (2027) using Power BI’s built-in AI capabilities.

📁 Repository Contents
Superstore_Analysis.xlsx: The cleaned dataset.

Analysis_Script.ipynb: Python notebook containing the automation and ML code.

Executive_Dashboard.pbix: The final interactive Power BI file.

Dashboard_Preview.pdf: A static export of the final visual report.

💡 Key Business Insight
"By analyzing the discount-to-profit correlation, I discovered that reducing discounts by just 10% in the Furniture category could potentially recover thousands in lost annual revenue."
